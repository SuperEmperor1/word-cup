# 世界杯预测系统 (World Cup Predictor)

工业级足球比赛概率预测系统，输出三类相互自洽的预测：

- **胜平负** (1X2) 概率
- **精确比分** 完整概率矩阵（最可能比分 Top-N）
- **进球数市场**：总进球分布、大小球各盘口 (0.5–4.5)、双方进球 (BTTS)、期望总进球

基于 1872 年至今 **49,000+ 场国际 A 级赛事**、**47,000+ 条球员级进球明细**、
**677 场点球大战**及各国地理坐标训练，内置 2026 世界杯全部赛程，
可逐场预测并蒙特卡洛模拟整届赛事的夺冠 / 进决赛 / 四强 / 出线概率。

## 数学方法论

系统采用 **三基模型 + Stacking 元学习器** 的分层架构，
全部为学术界与博彩业验证过的方法：

### 1. 加权 Elo 评分（World Football Elo Ratings 标准）

```
R' = R + K · G · (W − W_e),   W_e = 1 / (1 + 10^(−dr/400))
```

- **K 因子按赛事重要性**：世界杯决赛圈 60，洲际杯 50，预选赛 40，国家联赛 30，友谊赛 20
- **净胜球倍增 G**：1 球 = 1，2 球 = 1.5，N≥3 球 = (11+N)/8
- **主场优势**：非中立场地主队 dr 加 80 分

### 2. 时间衰减 Dixon-Coles 双变量泊松模型（比分核心模型）

Dixon & Coles (1997)，比分建模的行业黄金标准：

```
log λ = att_主 + def_客 + γ·主场      （主队进球强度）
log μ = att_客 + def_主               （客队进球强度）
```

- **低比分相关性修正 τ_ρ**：修正独立泊松对 0-0 / 1-0 / 0-1 / 1-1 的系统性偏差
- **时间衰减加权 MLE**：`w = exp(−ξ·Δt) × 赛事重要性权重`，半衰期约 2 年，
  友谊赛降权、大赛升权
- **解析梯度 + L-BFGS-B** 优化数百个攻防参数，秒级拟合
- 拟合集外的弱队由 **Elo→进球数泊松回归（IRLS）** 后备覆盖

### 3. 分数驱动动态攻防评级（score-driven dynamic Poisson）

Koopman-Lit 型在线评级，与 DC 的批量拟合互补：每场比赛后按
`att_i += k·(实际进球 − λ̂)` 即时更新攻防参数，对状态突变响应更快。
其输出 `sd_xg`（动态期望进球）是 GBM 中重要性仅次于 Elo 差的特征。

### 4. 梯度提升机（101 维防泄漏特征）+ xG 双头 + 平局专项

三个 GBM 头共享 101 维仅用赛前信息的特征：胜平负分类头、**平局专项二分类头**
（平局是三分类中区分度最弱的结果，单独建模后并入元学习器）、
**xG 双头 Poisson 回归**（直接回归主/客进球数，与 DC 强度几何混合，
混合权重与全局进球尺度在验证期以比分对数似然联合校准——修正了
市场回测发现的大小球系统性低估）。特征族：

| 维度 | 特征 |
|---|---|
| 实力评级 | 赛前 Elo（双方/差值/和值）、Elo 期望胜率、**Elo 一年趋势**（上升/衰退期）、**分数驱动攻防评级与动态 xG** |
| 状态与赛程强度 | 指数加权近 10 场与近 5 场积分率、场均进球/失球、**对手平均 Elo（赛程强度）**、**Elo 调整超额表现**、**不败连击**、**零封率** |
| 日程与地理 | 休息天数（含差值）、近 30 天比赛密度、**旅行距离 + 近 60 天累计旅途**、**时区差**、**气候错配**（纬度×举办地）、**场地海拔与海拔差**（墨西哥城 2240m 等静态表） |
| 比分演进 | **逆转拿分率 / 领先守成率**（由进球分钟重建比分进程）、**0-15 分钟早段进/失球占比** |
| 强弱与稳定 | **对 Elo>1750 强队的积分率**、**大赛/友谊赛表现差**、**Elo 波动率** |
| 球员级（进球明细） | **75 分钟后进球/失球占比**（体能与终局强度）、**点球依赖度**、**射手集中度 HHI**（阵容深度代理）、**核心射手近期状态**（前 3 射手近 120 天产出 vs 2 年基准，伤缺/哑火的内生代理） |
| 外部商业数据 | **FM2026 阵容**（最佳 XI 能力、轮换深度、门将、年龄、核心依赖、体能状态、伤停负担）、**转会市场身价**（对数 + 差值）、**博彩市场去水概率**（Shin 方法） |
| 经验与情境 | **近 8 年大赛场次**、**洲足联归属（由参赛史自动推断）**、**同洲对决**、近 10 次交锋净胜球、中立场地、赛事重要性 |

### 5. 有序 Logit（第三基模型）

利用 `负 < 平 < 胜` 的有序结构：潜变量 `s = Xβ`，切点 `c1 < c2`，
`P(客胜)=σ(c1−s)`。参数少、极稳健，与前两个模型形成结构互补。

### 6. Stacking 元学习器 + 校准

- **元学习器**：多项 Logistic 回归，输入三个基模型的对数概率 + 赛事
  重要性/场地情境，在独立验证期训练；温度参数在 **5 折交叉预测**上
  以对数损失最优化（避免元学习器自我评估）
- **IPF 比分矩阵调整**：缩放比分矩阵的胜/平/负三个区域，使其与融合后的
  1X2 概率精确一致 —— 保证比分、进球数、胜平负三类输出**内部自洽**
- **点球大战模型**：677 场真实点球大战拟合
  `P(赢) = σ(b·ΔElo/400 + c·先罚)`（b≈0.57, 先罚优势 c≈0.11），
  模拟中掷币决定先罚方

### 7. 外部商业数据层（FM2026 / 身价 / 赔率）

`data/external/` 下放入标准 schema 的 CSV 即自动接入（详见该目录
README；本仓库不分发商业数据，FM2026 请用游戏内编辑器自行导出）。
三条防泄漏与生效机制：

1. **as-of 对齐**：每期快照带日期，任一比赛只取赛前最近一期且未过期
   （FM 120 天 / 身价 400 天）的快照——杜绝未来信息泄漏；
2. **特征通路**：21 个外部特征列（阵容/身价/市场），历史快照积累后
   GBM 自动学习；训练期内全缺失的列自动剔除；
3. **即时调整通路 + 市场锚定**：伤停负担与体能状态映射为 Elo 当量修正
   （每 10% 阵容 CA 伤停 ≈ −40 Elo），仅作用于预测行、无需重训即生效；
   预测行带赔率时与 Shin 去水市场概率做线性池（默认 0.3 权重）。

`python scripts/make_demo_external.py` 生成**完全合成**的演示数据
（`data/external_demo/`）用于验证管线，切勿当真实数据使用。

### 评估协议：滚动前向回测（严格无泄漏）

基模型训练于 2002–2022，元学习器训练于 2023–24，**测试于 2025 年至今
1,313 场完全样本外比赛**，期间 Dixon-Coles 按季度仅用当时已发生的比赛重拟合：

**胜平负** (1,313 场):

| 模型 | RPS ↓ | Brier ↓ | LogLoss ↓ | 命中率 ↑ |
|---|---|---|---|---|
| **Stacking 融合** | **0.1574** | **0.4803** | **0.8214** | 62.1% |
| 单 有序 Logit | 0.1586 | 0.4840 | 0.8276 | 62.1% |
| 单 GBM (101 维) | 0.1597 | 0.4862 | 0.8296 | 61.8% |
| 单 Dixon-Coles | 0.1627 | 0.4918 | 0.8403 | 61.1% |
| 纯 Elo 基准 | 0.1652 | 0.5046 | 0.8631 | 61.8% |
| 频率先验基准 | 0.2274 | 0.6292 | 1.0444 | 48.7% |

**比分与进球市场**（同一测试集, 历史上常被忽略的验证维度）:

| 指标 | 本模型 | 基准 (常数泊松) |
|---|---|---|
| 比分多项对数损失 | **2.865** | 3.293 |
| 大 2.5 球 Brier | **0.2372** | 0.2498 |
| BTTS Brier | **0.2368** | — |
| 总进球 MAE | **1.409** | — |

大小球校准曾发现系统性低估（预测 28% 实际 35%），经 xG 双头混合
修正后各分桶已收紧（如 0.336/0.365、0.404/0.424）。

**特征族消融**（移除该族后的 RPS 退化, 全部为正 = 每族都在挣钱）:
context +0.00087, sd_rating +0.00088, player +0.00062,
progression +0.00049, geo +0.00035, schedule +0.00035。
分段诊断: 大赛 RPS 0.140 / 预选赛 0.158 / 友谊赛 0.161;
悬殊场 0.079 / 均势场 0.218（均势场是全行业难点）。

校准表显示各概率分桶的预测值与实际频率高度吻合（详见
`models/backtest_report.json`）。

## 使用方法

```bash
pip install -r requirements.txt

# 1. 更新数据（可选，数据已随仓库提供）
bash scripts/update_data.sh

# 2. 训练 + 回测（约 1 分钟）
python scripts/train.py            # 加 --no-backtest 可跳过回测

# 3. 预测任意对阵（默认中立场地；--home 表示第一队主场）
python scripts/predict_match.py "Brazil" "Morocco" --date 2026-06-13

# 4. 预测 2026 世界杯：72 场小组赛 + 官方支架蒙特卡洛 (16 参数世界)
python scripts/predict_worldcup.py --sims 20000 --worlds 16

# 5. 单场全市场: 让球盘/半全场/进球者/不确定性区间/特征归因
python scripts/predict_match.py "Brazil" "Morocco" --ah --ht --scorers     --uncertainty --explain

# 6. 生产化: 预测存档 -> 事后对账线上成绩单 / 每日自动更新
python scripts/archive_predictions.py && python scripts/score_archive.py
bash scripts/daily_update.sh
```

### 2026 世界杯模拟的官方精确性

- **官方 32 强对阵表**（比赛 73–88）与 16 强→决赛的完整对阵树
- **第三名分配**：8 个槽位的官方允许组别集合 + 二分图完美匹配
  （测试覆盖全部 495 种晋级组合）
- **FIFA 同分细则**：积分 → 同分子集相互战绩 → 净胜球 → 进球 → 抽签
- **末轮默契球**：双方均已锁定出线时平局概率上调 30%
- **参数不确定性传播**：DC 攻防参数按 Fisher 标准误抽样 16 个"世界"，
  球队强度在整届内保持一致——修正了点估计模拟的系统性过度自信
  （头部夺冠概率从 ~25% 回落到 ~14%，与市场定价一致）

## 精度边界（必读）

足球是**低进球、高随机性**的运动，单场结果的固有噪声极大。学术界与
博彩业的共识上限：顶级模型（包括博彩公司收盘赔率）的 1X2 RPS 约为
0.19–0.20（俱乐部联赛）/ 国际赛事因实力差距更大可低至 0.16 左右，命中
率约 55–65%。**任何声称能"精准预测"单场比分的模型都不可信**——本系统
的价值在于输出*经过严格校准的概率分布*：长期来看预测 60% 的事件就会
发生 60%，这正是工业级模型与玄学的区别。精确比分单点概率天然不会超过
~30%（最常见比分 1-0 的基础频率所限）。

关于提升空间的量化认识：当前 RPS 0.158 距离理论噪声下限的剩余空间
以**千分位**计——博彩市场收盘价（人类已知最准的足球预测）相对优秀
统计模型的优势约为 RPS 0.003–0.008。所谓"提升一个量级"在该指标上
不存在物理可能；真实的工程目标是: 吃满外部数据后逼近并偶尔超越市场。
各数据层的经验增量: 赔率特征 ≈ −0.003~−0.008 RPS，球员级阵容/伤停
≈ −0.002~−0.005，身价 ≈ −0.001~−0.003（与阵容高度共线）。
尚未接入的提升方向：出场名单（赛前 1 小时）、俱乐部赛事 xG、
天气与场地海拔、裁判倾向。`features.py` 特征表与 `external.py`
schema 均可直接扩展。
